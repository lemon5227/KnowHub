# enterprise-v1

自建合成评测输入，不含真实客户、真实企业政策或模型密钥。2026-10-23首次冻结并运行；不作为训练数据、线上指标或独立测试集宣传。

- `corpus.json`：27份合成知识文档，使用生产ingest生成81个片段。
- `queries.json`：60道中文查询、来源/章节正例，原始版本保留。
- `workflows.json`：24个独立初始状态及任务规则；期望项不发送给模型。
- `SHA256SUMS`：首次运行前原始3份输入的哈希。
- `judgment-errata.json`：观测排名后的公开标注勘误；保留原始与修正分数，不改变查询、语料或排名。

[完整结果、限制与复现命令](../../docs/benchmark-2026-10-23.md)。所有任务失败也公开；本轮8个提案任务没有生成结构化提案，不能包装为100%业务成功。
